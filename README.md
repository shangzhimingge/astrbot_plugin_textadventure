# AstrBot 插件：动态文字冒险（textadventure）

一个由 LLM（大语言模型）驱动的动态文字冒险小游戏插件，支持自定义冒险主题，AI 实时生成故事情节，带来沉浸式互动体验。

## 插件简介

- **名称**：textadventure
- **作者**：LumineStory
- **版本**：v1.0.0
- **描述**：一个动态文字冒险小游戏，由 LLM 作为游戏主持人（Game Master），根据玩家输入实时生成独特的冒险故事。

## 功能特性

- 支持自定义冒险主题（如奇幻世界、赛博朋克城市等）
- AI 实时生成场景、事件和行动选项，可为冒险单独选择聊天模型
- 可关闭行动超时，也可要求行动使用专用前缀
- 支持手动存档，退出后可读取并继续冒险
- 提供详细的游戏玩法说明和帮助指令

## 安装方法

1. 将本插件文件夹放入 AstrBot 插件目录。
2. 确保已正确配置并启用 LLM 服务（如 OpenAI、Azure 等）。
3. 在 AstrBot 管理后台或命令行启用本插件。

## 使用说明

### 启动冒险

```
/开始冒险 [主题]
```
- 例：`/开始冒险 在一个赛博朋克城市`
- 不指定主题时，使用默认主题（可配置）

### 输入行动

- 默认直接发送「检查宝箱」即可推进剧情。
- 开启「行动需要触发前缀」后，使用「冒险触发前缀」加行动内容。若前缀是 `>`，就发送 `>检查宝箱`。冒险期间，普通消息仍按 AstrBot 原有规则处理。
- 同一个前缀也适用于开始、结束和帮助，例如 `>开始冒险 奇幻世界` 和 `>结束冒险`。使用 AstrBot 唤醒前缀的原有指令也可继续使用。

### 剧情输出

在插件配置中设置「剧情输出模式」。设置作用于开场、行动结果和读档剧情。简短的等待提示仍以文字发送。

| 模式 | 效果 |
| --- | --- |
| 跟随 AstrBot | 默认模式。剧情走 AstrBot 的发送前处理，可交给 Output Enhance 等插件转图片。 |
| 文字 | 直接发送纯文字剧情。 |
| 图片 | 使用 Pillow 在机器人本机生成冒险日志卡片，长剧情自动分页。渲染失败时改用文字发送。 |

图片模式使用 AstrBot 的本地渲染字体。标准 Docker 镜像自带 Noto CJK 字体；如果自行部署时日志提示缺少中文字体，可在运行 AstrBot 的环境中安装 Noto CJK。图片模式也可识别常见的 Markdown 标题、粗体、引用和列表格式。

使用 Output Enhance 渲染时，选择「跟随 AstrBot」，然后在 Output Enhance 中启用文转图片，并将字数阈值设在常见剧情长度以内，例如 150 字。带引用或 @ 的消息会跳过该插件的文转图条件。

### 存档和读档

| 指令 | 用途 |
| --- | --- |
| `/存档冒险 [存档名]` | 保存最近一个已生成的完整回合。省略存档名时自动生成带时间的名称，并新建存档。手动使用同名会更新该存档。 |
| `/冒险存档` | 查看当前聊天中的个人存档列表，最新保存的在前。 |
| `/读取冒险 [存档名]` | 结束当前冒险后，读取指定存档并接着游玩。省略存档名时读取最新存档。 |

例如，在冒险中发送 `/存档冒险 雨夜矿井 入口`，退出后发送 `/读取冒险 雨夜矿井 入口`。自定义前缀也适用于存档指令，例如 `>存档冒险 雨夜矿井`。

存档名最多 40 字，支持文字、数字、空格、点、连字符和下划线。「旧版存档」是升级前单槽存档的名称，可用 `/读取冒险 旧版存档` 继续。

每个玩家可以在每个群或私聊分别保存多个存档。存档保存在 `data/plugin_data/textadventure/saves/`，重启后仍可读取。读档会按当前的冒险模型配置继续游玩。

### 结束冒险

```
/结束冒险
```
- `/结束冒险` 和 `/强制结束冒险` 都会立即退出，即使 AI 正在生成开场或下一幕。
- 冒险按玩家和当前聊天隔离。结束后，新消息按 AstrBot 原有的聊天规则处理。

### 查看帮助

```
/冒险帮助
```
- 查看所有可用指令和玩法说明

## 配置说明

插件支持以下配置项（见 `_conf_schema.json`）：

| 配置项                  | 类型   | 默认值   | 说明                         |
|-------------------------|--------|----------|------------------------------|
| default_adventure_theme | string | 奇幻世界 | 默认冒险主题（如赛博朋克城市）|
| session_timeout | int | 300 | 等待玩家行动的秒数。设为 `0` 关闭超时。 |
| trigger_prefix | string | `/` | 插件专用前缀。可以填写 `>` 或 `冒险`。 |
| require_action_prefix | bool | `false` | 是否只接收带专用前缀的行动。 |
| llm_provider_id | string | 空 | 冒险专用聊天模型的 Provider ID。留空使用 AstrBot 默认聊天模型。 |
| story_output_mode | string | 跟随 AstrBot | 可选「跟随 AstrBot」「文字」和「图片」。 |

可在 AstrBot 插件配置界面或配置文件中修改。在插件配置里打开「冒险模型」，选择 AstrBot 已启用的聊天模型并保存。新开的冒险从开场到后续回合都使用开局时选定的模型。普通聊天继续使用原有模型设置。
