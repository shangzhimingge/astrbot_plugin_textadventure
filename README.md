# AstrBot 插件：动态文字冒险（textadventure）

一个由 LLM（大语言模型）驱动的动态文字冒险小游戏插件，支持自定义冒险主题，AI 实时生成故事情节，带来沉浸式互动体验。

## 插件简介

- **名称**：textadventure
- **作者**：LumineStory
- **版本**：v1.0.0
- **描述**：一个动态文字冒险小游戏，由 LLM 作为游戏主持人（Game Master），根据玩家输入实时生成独特的冒险故事。

## 功能特性

- 支持自定义冒险主题（如奇幻世界、赛博朋克城市等）
- AI 实时生成场景、事件和行动选项，可为冒险单独选择聊天模型
- 可关闭行动超时，也可要求行动使用专用前缀
- 提供详细的游戏玩法说明和帮助指令

## 安装方法

1. 将本插件文件夹放入 AstrBot 插件目录。
2. 确保已正确配置并启用 LLM 服务（如 OpenAI、Azure 等）。
3. 在 AstrBot 管理后台或命令行启用本插件。

## 使用说明

### 启动冒险

```
/开始冒险 [主题]
```
- 例：`/开始冒险 在一个赛博朋克城市`
- 不指定主题时，使用默认主题（可配置）

### 输入行动

- 默认直接发送「检查宝箱」即可推进剧情。
- 开启「行动需要触发前缀」后，使用「冒险触发前缀」加行动内容。若前缀是 `>`，就发送 `>检查宝箱`。冒险期间，普通消息仍按 AstrBot 原有规则处理。
- 同一个前缀也适用于开始、结束和帮助，例如 `>开始冒险 奇幻世界` 和 `>结束冒险`。使用 AstrBot 唤醒前缀的原有指令也可继续使用。

### 剧情转图片

开场和每回合的剧情都经过 AstrBot 的发送前处理，可以由 Output Enhance 等插件转成图片。等待提示仍以短文本发送。

使用 Output Enhance 时，打开「文转图片 → 启用文转图片」，并将文本长度阈值设在常见剧情长度以内，例如 150 字。若达到阈值仍有部分消息以文字发送，可检查 Output Enhance 的自动引用设置。带引用或 @ 的消息不符合它的文转图条件。

### 结束冒险

```
/结束冒险
```
- `/结束冒险` 和 `/强制结束冒险` 都会立即退出，即使 AI 正在生成开场或下一幕。
- 冒险按玩家和当前聊天隔离。结束后，新消息按 AstrBot 原有的聊天规则处理。

### 查看帮助

```
/冒险帮助
```
- 查看所有可用指令和玩法说明

## 配置说明

插件支持以下配置项（见 `_conf_schema.json`）：

| 配置项                  | 类型   | 默认值   | 说明                         |
|-------------------------|--------|----------|------------------------------|
| default_adventure_theme | string | 奇幻世界 | 默认冒险主题（如赛博朋克城市）|
| session_timeout | int | 300 | 等待玩家行动的秒数。设为 `0` 关闭超时。 |
| trigger_prefix | string | `/` | 插件专用前缀。可以填写 `>` 或 `冒险`。 |
| require_action_prefix | bool | `false` | 是否只接收带专用前缀的行动。 |
| llm_provider_id | string | 空 | 冒险专用聊天模型的 Provider ID。留空使用 AstrBot 默认聊天模型。 |

可在 AstrBot 插件配置界面或配置文件中修改。在插件配置里打开「冒险模型」，选择 AstrBot 已启用的聊天模型并保存。新开的冒险从开场到后续回合都使用开局时选定的模型。普通聊天继续使用原有模型设置。
